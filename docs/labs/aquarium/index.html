Aquarium temperature and heater cycles on an Android tablet

The tank reads 25.4 °C. To see how it got there, put two charts on the same two-hour timeline: water temperature and heater state.

The owner's aquarium dashboard

Between 16:52 and 18:52 the water ranged from 25.2 to 25.6 °C. The stepped trace shows when the panel received an ON or OFF state. Pick a transition and follow the slope of the temperature curve after it.

Try it without a tank

You need Python 3 on a computer, ARAAMA on Android and a local MQTT broker. For publishing, install the Mosquitto client and check that mosquitto_pub runs in your terminal. The ZIP contains a generator and an importable panel with two current readings and two charts. The schedule and RGB controls belong to the real installation.

Download the generator and panel (ZIP)

Preview a message without a broker

Extract the ZIP, open a terminal in that folder and run this command. It prints the topic and one message, then exits.

python simulate.py --count 1
lab/aquarium/state {"water_temperature_c":25.52,"heater_on":1}

Send readings to the tablet

Replace the example address with your broker's address. Leave the terminal open. The generator publishes both fields every five seconds. If the broker requires a password, configure credentials locally for mosquitto_pub and in ARAAMA.

python simulate.py --host 192.168.1.20

Export any existing ARAAMA project. Open Settings → Projects, import panel.json, then replace broker.example under Network with the same broker address. Select Run and compare the readings with the terminal output.

Read the simulated heating cycle

The water gauge reads $.water_temperature_c in °C. Heater state reads $.heater_on (1 for ON, 0 for OFF). Both charts cover two hours. The model starts with the heater on, switches it off at 25.6 °C and back on at 25.2 °C. The rate of warming and cooling changes gradually. Watch for the first OFF transition after about a minute. These thresholds belong to the demonstration. The generator publishes telemetry only and sends no commands to equipment.

Stop the generator with Ctrl+C. To build this by hand, select both fields in MQTT search, save each as a tag and reuse it for a reading and a chart. The supplied panel was tested in 0.1.10. The lighter 0.1.5 is also available for small MQTT projects.
