ESP32 / BMP280 / MQTT

Барометр на подоконнике

По одному числу на барометре трудно понять, растёт давление или падает. Здесь ESP32 считывает BMP280, а на планшете рядом с текущим давлением появляется график. Вторую шкалу займёт температура самого датчика.

Что понадобится

Плата разработки ESP32-WROOM-32, USB-кабель для передачи данных, перемычки, Arduino IDE с пакетом плат ESP32 от Espressif, устройство с Android 8 или новее и MQTT-брокер, доступный обоим устройствам в локальной сети.

Модуль Adafruit BMP280 в режиме I²C. На этой плате SDI соответствует SDA, а SCK — SCL.

Готовый проект проверен в 0.1.10. Для небольшой MQTT-панели, которую собираете вручную, доступна и облегчённая 0.1.5. ARAAMA 0.1.10 · 110 MiB · ARAAMA 0.1.5 · 39 MiB

Подключаем датчик при отключённом USB

  • 3V3 → VIN
  • GND → GND
  • GPIO21 → SDI / SDA
  • GPIO22 → SCK / SCL

Загружаем скетч и проверяем первое сообщение

WindowPressure/WindowPressure.ino

Распакуйте архив. Откройте файл .ino из одноимённой папки в Arduino IDE, выберите плату ESP32 Dev Module и её порт. В менеджере библиотек установите PubSubClient и Adafruit BMP280 Library вместе с предложенными зависимостями. В пустые строки в начале скетча впишите название своей сети Wi-Fi и адрес своего MQTT-брокера. При необходимости заполните пароли у себя. Пример рассчитан на порт 1883 в доверенной локальной сети.

Загрузите скетч и откройте монитор порта на скорости 115200 бод. При успешном чтении датчика каждые пять секунд появляется сообщение JSON. Если настройки сети оставить пустыми, показания всё равно можно проверить через USB. После подключения к брокеру то же сообщение уходит в топик:

lab/window-pressure/state
{"temperature_c":19.1,"pressure_hpa":1008.3}

Скетч ищет BMP280 сначала по адресу 0x76, затем по 0x77. Библиотека выдаёт паскали, поэтому результат делим на 100 и на планшете ставим гПа. Это давление в точке установки. В прогнозе погоды оно может быть приведено к уровню моря.

Пробуем без платы и датчика

Генератор simulate.py заменяет ESP32 с датчиком. На компьютере он раз в пять секунд рассчитывает учебные показания. Они плавно меняются по формуле. Когда вы отправите их в брокер, ARAAMA примет обычное MQTT-сообщение и построит график по полученным значениям.

1. Посмотрите первое сообщение

Скачайте ZIP выше, распакуйте его и откройте терминал в папке, где лежит simulate.py. Для этого шага достаточно Python 3. Команда выведет одну строку и завершится:

python simulate.py barometer --count 1
lab/window-pressure/state {"temperature_c":18.6,"pressure_hpa":1008.0}

2. Отправьте показания на планшет через MQTT

Понадобятся работающий MQTT-брокер, доступный компьютеру и планшету, и клиент Mosquitto на компьютере. Проверьте в терминале команду mosquitto_pub --help. В примере адрес брокера — 192.168.1.20. Подставьте свой адрес и запустите:

python simulate.py barometer --host 192.168.1.20

Оставьте терминал открытым. По умолчанию используется порт 1883. Если ваш брокер требует пароль, задайте данные для публикации в локальном файле настроек mosquitto_pub, а данные для чтения — в ARAAMA.

3. Сверьте шкалу с сообщением

В ARAAMA откройте WindowPressure/panel.json через «Настройки» → «Проекты». Если на планшете уже есть проект, сначала экспортируйте его. В разделе «Сеть» замените broker.example адресом того же брокера и нажмите «Запуск». Сравните число в терминале с показанием шкалы. После нескольких сообщений на графике появятся точки.

4. Перейдите на настоящий датчик

Остановите генератор сочетанием Ctrl+C. В скетче укажите тот же брокер и запустите ESP32. Топик и имена полей совпадают, поэтому карточки продолжат работать с показаниями датчика.

Настраиваем карточки ARAAMA

WindowPressure/panel.json

Чтобы получить экран как на снимке, откройте «Настройки» → «Проекты», экспортируйте текущий проект и откройте нужный panel.json из архива. В разделе «Сеть» замените broker.example адресом своего брокера, введите данные для входа и нажмите «Запуск». У двух шкал и двух графиков всего два тега. Сверьте число на шкале с последним MQTT-сообщением и дождитесь нескольких новых точек.

Можно собрать экран вручную. Пока приходят сообщения, откройте «Поиск MQTT», выберите указанный выше топик и по очереди выберите два поля JSON из примера ниже. Сохраните каждую привязку как тег. Укажите единицы, добавьте по шкале на тег и включите историю. В карточках графиков выберите те же теги — повторно вводить адреса не придётся.

  • $.temperature_c → °C
  • $.pressure_hpa → hPa
